## Overview
The Currency Converter (Turkish Edition) is a streamlined web widget built for users who need instant exchange rate calculations without the complexity of external API keys or heavy dependencies. Tailored specifically for the Turkish market, it provides a clean, mobile-responsive interface for converting between popular global currencies and the Turkish Lira (TRY).

## Features
*   **Instant Conversion:** Real-time calculation logic using built-in demo rates.
*   **Swap Functionality:** Easily toggle between source and target currencies with a single click.
*   **Popular Currencies:** Pre-configured support for major global currencies (USD, EUR, GBP, TRY).
*   **Zero Dependencies:** No external API keys or build steps required.
*   **Responsive Design:** Optimized for both desktop and mobile browsers using Flexbox and CSS Grid.
*   **Lightweight:** Single-file architecture ensuring lightning-fast load times.

## Localization Notes
*   **Language:** The interface is localized for Turkish users.
*   **Formatting:** Uses standard Turkish decimal formatting (comma as decimal separator).
*   **Directionality:** Optimized for LTR (Left-to-Right) layout.
